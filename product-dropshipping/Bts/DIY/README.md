# DIY Build Kit (Multi-Run Project)

This folder is your **self-build curriculum** for rebuilding the same BTS dropship system multiple times:

1. Express + regular HTML
2. Express + HTMX
3. Hono + regular HTML
4. Hono + Alpine
5. Hono/Express + React frontend

Use files in this order:

1. `01_Problem_And_Principles.md`
2. `02_Architecture_And_Diagrams.md`
3. `03_Data_Model_And_SQLite.md`
4. `04_Implementation_Roadmap.md`
5. Backend track:
   - `05_Express_Track.md` **or** `06_Hono_Track.md`
6. UI choice: `07_UI_Tracks_HTML_HTMX_Alpine_React.md`
7. Security: `08_Auth_And_Authorization.md`
8. Reliability: `09_Testing_Observability_Operations.md`
9. Repetition method: `10_Repetition_Playbook.md`

---

## Outcome

If you follow this kit end-to-end, you should be able to implement the whole project yourself in both Express and Hono, and swap frontend styles without changing core business logic.
